# 官网首页产品化改造

更新时间：2025-01-21（Asia/Shanghai）

## 已完成：P0 高影响低成本优化（本地，未发布）

### 1. Hero 标题和痛点区文案重写
**目标**：从抽象价值主张到具体场景痛点，增强用户共鸣。

**Hero 区改进**：
- 标题从"不是看过。是终于读懂。"改为"一部 TED 演讲 / 从听不懂到听清每一句"
- 使用具体场景（TED 演讲）替代抽象表达，用户能立即联想到学习困境
- 副标题强调"停下来彻底理解"，突出核心差异化
- 注册说明从"无需支付"改为"永久免费版可用"，降低心理门槛

**痛点区改进**：
- 标题从"而是每次学习都从零开始"改为"学了很多材料，真正读懂的有几篇？"
- 增加表情符号（😓😔🤔）建立情绪共鸣
- 三个痛点从现象描述改为用户真实时刻：
  - "听了一半不知道讲什么"（具体化：反复拖进度条）
  - "刚查过的单词转头又忘"（具体化：词典和阅读是两个 App）
  - "学了很久看不到进步"（具体化：几个月后还是凭感觉猜）

**文件**：`frontend/src/pages/PublicSite.jsx` 第 347-355 行、`frontend/src/styles.css` 第 853 行

### 2. 互动演示区（降低理解门槛）
**目标**：让新访客在 30 秒内体验"逐句学习"的核心价值。

**功能实现**：
- 展示一句真实英语例句，两个橙色高亮单词可点击
- 点击后弹出 Tooltip 显示词性和中文释义
- 首次点击有提示文案引导："💡 点击橙色单词试试"
- 点击后单词变为绿色，标记已查看状态
- 底部说明"这只是一句。在拾页，每篇文章、每个视频都能这样逐句理解。"

**视觉设计**：
- 琥珀色渐变背景（#fff8f0 → #fef5eb）区分于其他区域
- 白色卡片容器，圆角 20px，轻微投影
- 英文句子使用 Georgia 衬线字体 28px，突出阅读感
- 单词下划线使用琥珀色 #f0a860，hover 变为陶土橙 #d97443

**文件**：
- 组件：`frontend/src/components/InteractiveDemo.jsx`
- 样式：`frontend/src/styles.css` 第 873-979 行
- 集成：`frontend/src/pages/PublicSite.jsx` 第 9、354 行

### 3. 信任元素注入（社会证明）
**目标**：通过真实数据降低信任门槛，提升转化率。

**后端统计接口**：
- 新增 `/api/public/stats` 公开接口（无需登录）
- 统计近 30 天活跃数据：
  - `totalSentences`：精读句子总数
  - `totalHours`：沉浸学习总时长（秒转小时）
  - `retentionRate`：30 天以上留存率（近 60 天用户基数）
- 缓存 5 分钟（`max-age=300`）
- 异常时返回零值，不影响页面展示

**前端展示**：
- 放置在产品故事区和定价区之间
- 三栏布局，每栏显示一个指标：
  - 大号数字（48px 绿色 #2f6f50）
  - 指标说明（16px）
  - 时间范围标签（13px 灰色）
- 数据为零时不展示该区域（优雅降级）
- 超过 1 万自动格式化为"X.X万"

**文件**：
- 后端：`tools/reader_server.py` 第 259-260、1003-1027 行
- 前端组件：`frontend/src/components/TrustSection.jsx`
- 样式：`frontend/src/styles.css` 第 982-1049 行
- 集成：`frontend/src/pages/PublicSite.jsx` 第 10、373 行

### 5. 套餐对比两阶段展示
**目标**：降低认知负担，先理解档位，再看详细权益。

**第一阶段（简化卡片）**：
- 只显示：名称、定位（体验/日常/重度）、价格、选择按钮
- 去除详细权益列表、支付方式说明
- 卡片高度统一，hover 上浮 4px
- "查看详细权益对比"按钮居中

**第二阶段（对比表）**：
- 横向表格，左侧权益名称，右侧 3 列对应 3 个套餐
- 表头推荐方案列使用绿色背景 #eef5ed
- 行 hover 效果，增强可读性
- 表格下方并排显示 3 个选择按钮
- "收起详细对比"链接按钮

**状态管理**：
- 使用 `useState` 控制 `showComparison` 布尔值
- 默认简化模式，点击后展开对比表
- 两种模式共享同一定价数据源

**文件**：
- 组件：`frontend/src/pages/PublicSite.jsx` 第 60-142 行

### 6. 新配色系统引入
**设计原则**：从"安全的教育绿"转向"温暖的理解橙"，建立差异化视觉身份。

**核心色彩**：

- 辅助色（琥珀色）：`#f0a860`（次级强调、演示区）
- 理解绿松石：`#4a7c6f`（已点击状态）
- 背景暖白：`#f8f6f1`（从 #f6f5f1 微调）

**应用范围**：
- 首页所有主按钮（.ant-btn-primary）使用陶土橙

- 互动演示区单词高亮使用陶土橙 + 琥珀色下划线
- CSS 变量新增 `--study-accent` 和 `--study-accent-soft`

**向后兼容**：
- 只更新首页公开站点（.public-site）
- 学习空间保持现有主题切换功能不变
- 阅读器保持护眼模式不变

**文件**：
- 全局变量：`frontend/src/styles.css` 第 1-2 行

## 预期效果
