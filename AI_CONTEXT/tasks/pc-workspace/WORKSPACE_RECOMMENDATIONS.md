# 学习空间与模块联动审查

日期：2026-10-20。仅产品审查与建议，未改业务代码或正式数据，未发布。

后续实施状态（同日）：P0 口径修正与 P1 首页计划、复习恢复、今日成果、阅读结算/指定新词复习、书架任务收起已落地本地；P2 奖励有效性/中文化已实现，购买恢复沿用既有流程。下文保留审查时的证据与原始建议，实施与验证以 `HANDOFF.md` 的“首页学习闭环落地”为准。内容画像推荐、首页专属指标埋点及通知不在本轮交付范围。

## 目标与证据

学习空间应帮助用户决定本次做什么、接着完成、看见成果、知道何时回来。保留现有深绿暖白及 React + Ant Design 体系。

本轮使用本地真实会话只读检查，截图位于 `.local/debug/product-design/workspace-audit-20261020/`；编号对应 01 学习空间、02 书架、03 学习记录、04 奖励、05 会员、06 书城、07 复习、08 阅读器。截图均保存并查看，overview 为上述截图裁剪拼版。初次 fullPage 截图侧栏异常，已用正常 viewport 截图替换，不作为产品缺陷。

## 优先修正事实与口径（P0）

1. 学习空间与学习记录的继续阅读不同：前者是 YouTube 学习视频、后者 THINK and SPEAK in English。源码确认二者选取逻辑不同。统一按可访问、当前书架、最近进度、未完成选取，返回相同读物及句子；归档/删除/权限失效应有替代入口。
2. 首页 0 到期词写“已复习完”，但零到期不能证明当日练习。使用新复习汇总，分别表达当前无到期、今日实际练习、下一到期；存在 active 会话时优先“继续本轮 x/y”。本轮截图没有 active，会话缺失风险由首页源码确认，不声称浏览器已复现。
3. 首页“连续学习”实际读取奖励签到 streak；源码按 checkins 计算，不等于连续听读/复习。要么改为连续签到，要么新增按真实学习事件计算的连续学习。周勾选同时接受阅读/句子/复习，而标题只有听读分钟，须标注活动类型。
4. 奖励仍展示“1次官方读物解锁”“1次 MP3 智能导入”，与现行按收藏容量控制不同；Pro 已有 AI 不限次仍展示 AI 次数兑换。必须先核对真实收益，停止提供不再产生作用的兑换选项，保留历史回执；本轮未执行兑换，不能声称扣分故障已复现。
5. StatsPage 待复习使用父级 vocabulary，但 main.jsx 仅 workspace 加载该列表。直达学习记录可能没有可靠的待复习数据，属于源码发现，需下一轮直接路由验证并改为页面自己的真实汇总。

## 首轮改版（P1）

- 首屏“本次学习”：用户可选短时听读 + 一轮复习作为计划；时长只作为预算，不伪装精确完成时间。保留一个最明确的主操作，用户仍能直接选择听读或复习。
- 主区“继续学习”：保留封面、原句位置和继续按钮；补充本次范围/停止点（有可靠句子时间轴时才展示估时），支持换一篇。
- 右区“复习安排”：优先未完成会话，其次到期队列，否则展示真实今日成果与下次到期，跳转应恢复对应状态。
- 第二行“今日成果”：听读时长、实际复习词数、新收藏词数分开；计划完成不等于长期掌握。周目标由用户设定，120 分钟降为可调整参考值。
- 阅读器保存成功后提供轻量结算：本次真实时长/新增词汇 → 去复习本次生词或回学习空间。现有队列尚不支持按本次收藏过滤，需要补充服务端范围，不能仅改按钮文案假装已有。
- “书架中的其他读物”缩为近期最多 2–3 本；书架内完成导入任务默认收起，进行中/失败才突出。当前截图的历史完成任务挤占首屏，应把学习材料前移。
- 内容发现只展示少量下一篇备选，先基于真实标签/时长/现有级别给出可解释筛选，不宣称个性化推荐或编造等级。

## 商业承接（P2）

- 学习空间只在真实触限、会员临近到期、已有购买待恢复时显示对应提醒；显示原因和操作，避免常驻大促销区干扰学习。
- 触限后沿用现有同页权益比较/云猫兑换/恢复原操作；保留读物、句子和复习会话。免费基础复习不加新的付费拦截。
- 成长奖励按当前账号实际可获得的权益展示，显示差多少成长值及可达成的真实学习条件；签到与学习奖励分别命名，事件名中文化。
- 衡量：首页主操作启动率、真实保存率、复习开始/完成率、次日真实学习回访率、触限后恢复原操作率。只看到页面/点击购买不能算完成学习或支付成功。

- 本轮仅文档，执行 git diff --check；未更改代码，不重复构建或业务写入测试。
