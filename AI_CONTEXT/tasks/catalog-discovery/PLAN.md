# 拾页 PC 书城查找与筛选方案

日期：2026-10-24。状态：设计建议，待用户评审；不包含业务实现或已验收的视觉稿。

## 设计判断

定位为英语学习选材目录：用户需要先判断“是否感兴趣、能否读懂、现在能否完成”，再试读和收藏。优先方案为顶部搜索、分层筛选、可比较的内容卡片；延续现有 React + Ant Design 和账号主题。

当前只有 6 条公开视频，不适合引入第二条常驻侧栏、大幅运营轮播或大量空分类。内容数量、分类密度和用户任务验证后，再考虑专用浏览页或侧栏。

## 已核对的现状

- `CatalogPage.jsx` 已有关键词、难度、系列、主题标签、资源类型筛选，单维度单选；详情支持原内容前 10% 试读及加入书架，已有加载、错误与空态。
- 搜索提示为标题、作者或主题；`saas_catalog.py` 实际匹配标题、英文标题、作者、系列名称，尚未匹配主题标签和描述。
- 初始与筛选请求固定 `limit=60`；后端最多 100，未返回总数、分页或可选择排序。超过结果上限的内容不能继续浏览。
- 难度选项来自已加载的最多 60 条与当前结果，并非全目录聚合；系列/标签数量为全目录数量，不随当前条件变化。
- 列表 API 未返回 description，卡片使用共用描述函数回退；未来应返回真实短介绍。
- 本地公开 API 当次返回 6 条，全部 `youtube`，难度均为空、标签均为空，均有预计分钟字段。标题出现 B2-C1 不能替代正式难度标注。
- 登录态书城未能打开，浏览器显示“无法读取登录状态”。以上产品诊断来自代码和真实公开 API，不作为已完成的截图审计。

## 用户任务与页面结构

1. 已知目标：搜索标题、作者、频道或系列，精确定位。
2. 有约束：选择难度、可用时间和主题，比较结果后试读。
3. 暂无目标：从实际有内容的主题或“短内容”快捷条件进入，再逐步收窄。

沿用全局导航，主内容从上至下全部左对齐：

- 紧凑页头：书城、简短说明、我的书架入口；搜索占主要宽度，常显文字标签。
- 常用筛选：英语难度、内容时长、主题；内容形式与频道/系列进入“更多筛选”，有选择时显示数量。
- 条件摘要：可逐项删除的已选条件、“清除全部”；结果数和排序紧贴列表。条件允许换行。
- 结果：PC 默认三列、每页 12 条；按可用宽度降低列数。窄 PC 优先保障长标题可读，不加第二条侧栏。
- 分页与总数：服务端分页，支持访问全部结果。

只有存在多个内容形式且用户需要区分时才显示“全部 / 视频 / 音频 / 文本”的快捷入口；当前全为视频时省略该行。频道/系列较少时可直接显示在常用筛选中，具体以真实数据决定，不为固定布局保留空控件。

## 筛选定义

| 维度 | 规则 |
| --- | --- |
| 难度 | 采用经过审核的 CEFR A1–C2，辅以中文说明；迁移前保留原等级原文，未分级单独列出；不直接把“中级”强行映射 B1 |
| 时长 | 少于 5 分钟、5 至不足 15 分钟、15 至不足 30 分钟、30 分钟及以上；使用秒级区间避免整数边界歧义 |
| 主题 | 运营维护约 6–8 个稳定主题，每条 1–2 个主主题；只展示有内容的主题。发音、跟读等学习用途与生活、科技等题材要区分，暂不新增一排混杂标签 |
| 内容形式 | 视频合并 `video` 与 `youtube`；YouTube 为来源。音频与文本单列；类型须依据真实媒体能力，不能仅因有字幕就归为音频 |
| 频道/系列 | 用于找到 Rachel's English 等连续来源；选项可搜索。后续有完整书籍时，可按系列顺序浏览，但需要真实序号字段 |
| 书架状态 | 更多筛选提供“隐藏已加入书架”；默认不隐藏 |

同一维度多选取并集，不同维度取交集。对难度、主题采用多选；时长区间也可多选；频道/系列首期单选即可。

时长必须区分“原音/视频时长”与“预计阅读用时”：视频显示原片时长，文本显示预计阅读用时，统一控件提示含义。当前 estimatedMinutes 仅为可用字段，实施前核对生成口径；未知值不当作 0，不进入短时长结果，可选择“时长未知”。精读、暂停和跟读耗时不承诺等于原片时长。

筛选选项来自全目录聚合。关联数量随当前其他条件变化：计算某维度时排除该维度自身，避免选一个值后同组其他选项全部消失；已选项即便为 0 也保留并可移除。零结果项不藏起来制造布局跳动。

## 搜索、排序与结果反馈

- 搜索覆盖中英文标题、作者、频道/系列和已审核主题；短介绍可低权重参与，正文全文搜索后置。
- 中文主题词通过真实中文标注、别名匹配英文内容。英文大小写、首尾空格和常见标点规范化；不承诺自动跨语言语义搜索。
- 有搜索词默认按相关性：完整标题、标题前缀、标题包含优先于来源、主题与介绍；没有搜索词默认精选顺序。显式切换排序后尊重用户选择。
- 首期排序：精选/相关性、最新上架、时长由短到长。收藏和阅读人数可保持真实展示，但暂不将累计人数称为“近期热门”。
- 输入防抖约 300ms，Enter 立即搜索；中文输入法组词期间不发送中间搜索。请求失败保留条件和可用结果，显示重试；旧请求不能覆盖新结果。
- URL 保存关键词、筛选、排序和页码；条件改变回第一页，返回列表恢复滚动与页码。全新进入不强制恢复可能误导用户的旧搜索。
- 零结果明确显示条件组合，并提供“移除时长条件”等可操作建议；建议数量必须由后端计算，不能编造。不得自动放宽筛选并将不匹配内容混入结果。

## 卡片与试读

卡片的信息顺序：真实封面、可读标题、频道/作者、难度与时长、最多两个主题、一句真实内容说明、明确操作。长英文标题支持 2–3 行，完整名称通过详情或键盘可访问提示读取，不能只依赖 hover。

未加入：主操作“试读”，次操作“查看详情”；已加入：主操作“开始阅读”，次操作“查看详情”。前 10% 的现有真实试读可沿用，点击即可验证难度与原音，不再强制先经过介绍弹窗。

详情负责完整介绍、频道/系列、预览、版权和收藏规则。“加入书架”只加入并反馈成功；需要加入后打开时按钮必须叫“加入并开始阅读”，修正当前文案与行为不一致。套餐触限继续使用现有升级闭环。

## 视觉约束

沿用浅色阅读工作区，默认建议：纸白 `#FFFFFF`、页面底 `#F6F8F7`、正文 `#263A32`、次级文字 `#61736A`、分隔线 `#DDE5E0`、强调绿 `#2F6F50`。强调色与选中背景绑定现有主题变量，雾蓝、鸢尾紫账号跟随当前主题。

沿用现有字体栈 Inter / PingFang SC / 系统无衬线，不新增装饰字体。页标题 24–28px，内容标题 16–18px，正文与筛选 14–16px。视频用 16:9 原首帧，文本保留现有书封组件；真实内容承担视觉辨识度。

区别于泛用商城：不加入促销横幅、装饰渐变、排行榜或无依据的“适合你”评分；把空间用于标题、难度、时长和试读。筛选与信息层次靠对齐和间距组织，不在每层再套卡片。保留可见焦点、键盘操作、稳定加载布局和读屏结果通知；具体可访问性仍需浏览器验证。

## 实施顺序与验收

首期：核对并补齐现有 6 条的中文简介、难度、主题、时长；补搜索语义、分页/总数/排序/筛选聚合；重组顶部筛选与卡片；接入 URL 状态及直接试读。内容标注未经审核不得伪装为确定等级。

后续：内容规模扩大后再做搜索联想、保存筛选、系列聚合；有真实学习画像及解释依据后再做难度匹配和个性化推荐。移动端按项目约定后置。

验收任务：搜索 Rachel's English 找到对应来源；中文主题找到已标注英文内容；组合难度与短时长正确返回或清楚解释空结果；超过一页仍可访问全部；试读返回恢复筛选/页码/滚动；缺失难度和时长不误导；真实试读、收藏、失败重试和权益触限保持正确。

后续指标候选：从进入书城到首次试读的用时、搜索零结果率、筛选后试读率、试读后加入书架率。先建立真实基线，不为当前方案虚构提升比例。
