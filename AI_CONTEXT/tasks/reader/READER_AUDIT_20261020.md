当前已有续读、原媒体控制、查词、句法、跟读和学习结算的基础。优先优化「顺畅阅读 → 理解当前句 → 明确收藏 → 短句练习 → 保存成果 → 下次继续」之间的连接。保留当前暖灰绿主题与正文/学习工具分栏。

### 1. 续读进入

![01 阅读器首屏](/Users/x/Documents/english/.local/debug/product-design/reader-audit-20261020/01-reader-entry.jpg)

优点：恢复第 4 句，正文清楚，主内容与工具分离，顶部操作克制。

问题：页面内没有「已恢复到第 4/5 句」说明；纯文本仍保留 00:00 播放条、时间轴、倍速和播放快捷键。右栏空态占据整列。

建议：头部增加轻量进度与保存状态；无媒体改成阅读进度/上一句/下一句，明确「此材料未附原音」。未查词时右栏可收起，保留展开入口。一般文章提供连续段落阅读，逐句卡片保留给精读练习；不能把五句短夹具的留白当成长文章缺陷。

### 2. 查词

![02 单词详情](/Users/x/Documents/english/.local/debug/product-design/reader-audit-20261020/02-word-detail.jpg)

优点：完整词典在语境服务失败时仍可使用；音标、发音与释义有基本层级。

问题：通用词典三组重复近义释义在前，「当前语境」在后；私人释义和备注默认展开，首屏看不到底部保存按钮。未展示所查词的来源原句。AI 配置错误是隔离环境条件，不应推断正式环境也不可用；但失败时仍显示「点击单词后会结合当前句解释」的默认说明，没有直接重试操作，属于已观察到的失败体验问题。

建议：顺序改为「词/音标/按需发音 → 来源原句与本句含义 → 收藏 → 搭配 → 更多词典 → 折叠笔记」。不把通用词典释义标成语境结论。分区独立加载、独立失败、独立重试。

代码补证：`ReaderPage.jsx:74` 使用 `Promise.allSettled` 后一次展示词典和语境，较慢服务仍会阻塞较快结果的展示；建议各区逐步显示。`ReaderPage.jsx:70–74` 点击词自动发音、悬词即暂停，建议提供自动发音/悬词暂停偏好并加悬停意图延迟；本轮没有原音，尚不能断言存在播放竞争故障。

### 3. 收藏与认识程度

![03 认识程度保存后](/Users/x/Documents/english/.local/debug/product-design/reader-audit-20261020/03-word-saved.jpg)

实际点击「不认识」，反馈为「认识程度已记录」。四档按钮能保存，但用户缺少明确的「加入生词本 / 已收藏」状态，也不知道保存后会进入复习。当前测试词原本已收藏，因此本轮结算新词为 0 是正确结果。

建议：收藏与自评分开；一键收藏保存词、原句和可用释义后提示「已加入生词本」，再可选自评。避免仅查词就强迫填写认识程度。请求中禁重复点击，成功状态持久显示，失败原位重试；撤销收藏需解释会影响复习记录。本文不修改现有调度规则。

![10 学习结算](/Users/x/Documents/english/.local/debug/product-design/reader-audit-20261020/10-session-summary.jpg)

优点：真实保存成功，提供继续/回学习空间，分开呈现时间、句子与新词，没有把浏览当作掌握。

建议：名称改为「本次学习活动时间」或清楚说明估算口径；句子按显式学习操作或可解释的阅读事件统计，播放位置与分析选择分开保存，不以显示/点击宣称掌握。结算列出本次收藏词和练习句，并依据真实结果选择主按钮。无新词时允许复习本篇已有词；若要新增该动作，需接真实 API，不能伪造复习结果。

## 调整优先级与验收标准

| 优先级 | 调整 | 验收标准 |
| --- | --- | --- |
| P1 | 显式收藏与已收藏状态 | 查词后能独立收藏，不需先评分；在生词复习看到同一来源原句；失败可重试 |
| P1 | 专注模式可见的操作结果 | 查词/句法无需退出专注即可查看并关闭，恢复阅读位置 |
| P1 | 无媒体能力状态 | 无 00:00 假播放器、无可点但不响应的原音动作；说明无原音且不以 TTS 冒充 |
| P1 | 离开保存保障 | 返回/刷新后的处理明确；失败可恢复；重试不重复计时 |
| P1 | 词典/语境分区显示及恢复 | 任一区先完成即可先读，服务失败保留原句和可用结果 |
| P2 | 正文阅读与精读排版 | 连续段落与逐句练习可切换，字号/行距/宽度偏好可保存 |
| P2 | 练这一句流程 | 从目标句进入原音、录音、对比、下一句，状态一致 |
| P2 | 可解释的学习成果 | 活动时间、学习句子、收藏、练习分别计量；末句位置不冒充完成或掌握 |
| 待原媒体复验 | 悬词意图、发音与原声恢复、字幕跟随 | 连续鼠标移动不频繁打断；用户手动暂停后不意外恢复；离开字幕跟随后可一键回当前句 |

首轮建议完成前五项；第二轮再做正文排版和句子练习。商业价值应在阅读过程中体现为准确的本句理解、稳定原音、可复习积累。套餐提示放在真实权益触限处，保留已读内容和继续操作；本轮未走购买流程，不判断转化效果。

可观察的后续指标：首次阅读到首次收藏、结算到复习、次日续读的转化，以及失败/重试率。先建立基线，再验证改版，不预设提升数值。

## 无障碍与证据限制

- 已观察：正文词是 button，翻译有展开语义，主要图标有部分命名；私人释义/笔记 textbox 的 DOM 快照没有关联名称，评分按钮只靠样式显示选中，时间轴/倍速缺少清楚的用途名称。需补 `label`、`aria-pressed` 或合适选择语义及读屏名称。
- 风险：逐词按钮会带来大量 Tab 停靠，专注的淡化文字和小号说明有对比度风险。建议验证句级导航、词级导航和返回正文焦点，不仅验证鼠标。
- 未测试：完整键盘路径、读屏、量化对比度、200% 缩放、长文章性能、正式 AI 成功结果、实际音视频同步/清晰度/倍速、麦克风录制、官方试读/购买。不能据此宣称无障碍达标或原媒体全链路通过。
- 当前夹具只有五句纯文本，适合证明状态与流程问题，不能代表长文排版质量、翻译质量或学习成效。
