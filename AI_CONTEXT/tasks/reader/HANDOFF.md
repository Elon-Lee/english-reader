# PC 阅读器交接

## 目标

React 阅读器的布局和交互语义与旧阅读器一致，同时使用 SaaS API 和鉴权媒体。

## 已完成

- 2026-10-18 视频默认流畅；阅读器读取服务端当前会员画质权限，免费版不会加载高清源，点击“高清 · 会员”走同页套餐购买/兑换，生效后重新取得阅读数据并保留播放位置切换。缺少 low 变体时明确提示，禁止回退原视频；官方试读与私人视频均适用。构建、modern/UI/JS、隔离库媒体与试读回归通过；本地后台已重启，本地 7/7 条已关联可阅读视频均有 low，另 1 条无 low 原件属于失败的导入任务且未关联书籍；未发布生产。
- 页面结构：媒体区、滚动字幕区、右侧“单词 / 句法 / 跟读”工具区。
- 顶部媒体按钮只切换媒体左侧/上方位置，带 Tooltip；媒体关闭后可重新打开。
- 顶部布局按钮复用旧版三块媒体/正文/词典示意图语义，使用当前主题的暖橙、鼠尾草绿和深绿；护眼按钮使用旧版 `◐ / ●` 状态反馈，但颜色跟随当前浅草绿主题。
- PC 阅读器头部从浏览器顶部开始，固定 70px 高；`OFFICIAL/PRIVATE READER` 与读物标题单行展示并截断过长标题，右侧四个按钮统一为 38px 高。
- 视频变体支持清晰度选择；媒体使用 `/api/media/*`。SaaS 视频/YouTube 新导入会保留原始源为“高清”，并用 FFmpeg 生成 360p H.264“流畅”变体；历史 PostgreSQL 视频已全部回填，当前 11/11 个视频都有 `low` 变体。
- PC 阅读器锁定为单视口布局：冻结头部和底部播放器不再带动页面外层滚动；字幕列独立滚动。媒体上方布局中视频按原始宽高比和可用高度自然缩放、居中显示，不拉伸到字幕宽度，也不添加额外黑边；纯 MP3/无画面时正文与右栏整体居中。
- 视频清晰度与关闭按钮已按旧版放进画面右上角浮层，视频无边框、保留圆角；有变体时只展示视频变体，避免把原始源重复显示为一个清晰度。
- 视频右上角“高清 / 流畅 / 关闭”默认隐藏，只在鼠标进入视频区域或键盘焦点进入媒体控件时显示。
- 视频使用 `controlsList="nodownload noremoteplayback"`、禁用画中画并阻止右键菜单，原生控件不再提供下载入口。用户在视频原生控件修改倍速时，底部倍速选择同步更新。
- 原始音视频时间驱动句子定位和单词高亮；缺少词级时间时按句子时长估算。
- 当前词使用与旧版语义一致、但适配现主题的暖橙底白字；当前句使用鼠尾草浅绿和暖橙左侧线，区分播放层级。
- 词级高亮在词与词之间的时间空隙继续停留在上一个已开始的单词，不再在句中停顿时消失。
- 逐句上一句、复读、下一句、播放暂停、时间轴、倍速、句末暂停。
- 底部播放条改为圆角浮层卡片：主播放按钮 48px 深绿圆形、时间轴使用暖橙进度、倍速宽度收紧到 64px。快捷键提示浮动在播放条上方，尾部设置按钮打开阅读器内“播放与快捷键设置”弹窗；四个快捷键与句末暂停在弹窗内保存并立即生效，不再跳转系统设置，播放条不再常驻句末暂停开关。
- 主播放/暂停按钮不再使用带圆圈图标嵌套圆形按钮；改为单一 48px 深绿实心圆，播放为简洁三角、暂停为双竖线，并提供 hover、pressed、focus 和 disabled 状态。
- 滚动字幕卡片不再显示“第几页”。句子交互已按旧版恢复：普通 hover 使用整块浅灰背景，不用边框/阴影强调；当前播放句使用浅绿背景和左侧强调线；“语法 / 翻译”小按钮内联在真实句尾，默认隐藏，只在整句 hover 或键盘焦点进入时显示。翻译展开为句子下方暖色说明块，移开句子后内容继续保留。
- 快捷键始终监听：默认 A/S/D/空格，Q 切换句末暂停；输入框编辑时不拦截。
- 单词语境、生词、私人释义、标注、复习评分、句法分析、录音回放和学习活动保存。
- 鼠标悬停单词会暂停原媒体并通过 `/api/word-hover` 展示简义，移开后恢复；点击并行请求 `/api/word-dictionary` 完整词典与 `/api/word-context` 语境分析，任一服务失败时保留另一部分结果。
- 完整词典响应会合并本地 ECDICT 音标；单词标题旁提供声音图标。点击正文单词后自动请求 `/api/word-tts` 播放一次后台音频，声音按钮可再次调用同一接口，不使用浏览器 `speechSynthesis`。
- 连续点击不同单词使用请求序列保护，较慢的旧响应不会覆盖最后一次选择；切换单词/句法标签时右栏回到顶部。键盘聚焦单词也会触发与鼠标悬停一致的简义与暂停行为。
- SaaS 已放行鉴权后的 `/api/word-hover`、`/api/word-dictionary`、`/api/word-tts`；`/api/word-context` 支持前端传入词文本、导入词数组中的标点索引以及已解锁官方读物，并继续校验用户读物权限。
- 护眼模式与专注模式已实现；专注模式隐藏媒体和右栏但不禁用快捷键。
- “完成学习”未提交前为白色次要按钮，保存成功后才显示深绿色“已完成”状态。
- 右侧“单词 / 句法 / 跟读”使用深绿、紫灰、雾蓝区分选中状态；阅读标题与正文使用衬线字体，工具和解释使用无衬线字体，保持信息层级统一。
- 右侧工具面板完成紧凑化：12px 内边距、8px 内容间距；词典不再用整块同色卡片，而是用词性彩色标签加释义行。单词认识度提供“不认识 / 困难 / 记得 / 简单”，私人读物和已解锁官方读物均真实保存到 PostgreSQL；私人释义与备注折叠展示。句法和跟读面板同步收紧卡片、标题和状态间距。
- 专注模式保留一个不可见的原始视频播放实例，播放、时间轴、倍速、快捷键和词级高亮继续工作；进入/退出专注模式会保留播放时间，并在原本播放时恢复播放。
- 视频画质切换显式保存当前时间、播放/暂停状态和倍速；新清晰度加载后恢复状态，真实验收从高清切换到流畅后时间继续前进且保持播放。
- 视频左右/上下布局切换同样保存并恢复时间、倍速与播放状态；底部播放/暂停图标以恢复后的真实媒体状态为准，不再出现媒体暂停但按钮仍显示播放中的错位。
- 专注/普通模式按钮提供动态 Tooltip；布局按钮分别提示“切换为视频上方”或“切换为视频左侧”。视频圆角由 16px 收紧为 10px。
- 播放条当前时间和总时长使用固定 42px 宽并居中；布局切换按钮加宽到 46px。
- 倍速控件去掉右侧下拉箭头的视觉占位，速度文字在 64px 控件中几何居中。
- 播放与快捷键弹窗中的句末暂停改为独立设置行，包含明确标题、说明和右侧紧凑开关，不再占据弹窗下半区。
- 阅读器路由会直接加载数据库偏好，并在父级偏好异步返回后同步本地播放状态；句末暂停保存后刷新不会回退到默认值。
- 右侧单词/句法/跟读面板默认隐藏滚动条；鼠标移入或键盘焦点进入面板时显示细滚动条。
- 句子列表默认间距由 10px 收紧到 7px，正文卡片内边距同步压缩；紧凑模式使用 5px 间距。
- 句末自动暂停改为检测播放时间是否跨越当前句末，即使浏览器 `timeupdate` 跳过精确阈值也会回到句末前约 30ms 并暂停；真实视频第一句在 3.08s 停止并更新播放按钮状态。
- 护眼模式覆盖整个阅读器系统：背景、头部、按钮、字幕卡片、当前句、右侧工具栏、播放器、快捷键浮层、速度控件和翻译块统一采用低对比度暖灰绿主题，不再只修改正文区域。
- 最近阅读句子使用独立 `/api/workspace/progress` 轻量接口防抖保存，不计学习时长、不发奖励。私人读物和已解锁官方读物都映射到 `workspace_progress`；刷新后恢复到上次句子的起始时间。真实官方视频验收第 5 句刷新前后均为句子 5、时间 00:23。
- 播放和跟读使用原始媒体，不用浏览器 TTS 代替原音。
- “流畅”视频生成不再移除音轨：新导入和补齐脚本都映射可选原始音轨并编码 AAC；本地 5 个真实源视频的既有无声 `low` 变体已原子替换并同步 PostgreSQL 文件大小、摘要、空间用量和审计记录，FFprobe 均确认同时包含视频轨和音轨。
- React 阅读器只从非 `generated` 的规范视频资产组装高清/流畅选项，避免历史生成资产被误识别为另一组画质。
- 视频上方布局改为独立网格行：视频区域保持浮层工具条，但不覆盖字幕或右侧学习工具，字幕继续在剩余高度独立滚动。
- PC 视频上方布局增加独立的居中浮动容器：视频按原始比例限制在 760px / 36vh 内，浮动阴影保留；容器本身参与网格占位并裁切越界内容，句子从下一行开始，避免媒体覆盖背景句子。已在本地真实视频读物的 1862×968 与 1280×720 视口测量，视频与句子滚动区重叠均为 0px。
- 底部倍速控件收紧到 54px；句末暂停关闭时使用暖橙描边胶囊突出状态。
- 单词、句法和跟读的加载状态统一在右栏居中展示；句法与跟读标题、正文、卡片和按钮字号已收紧。
- 私人释义与备注默认展开，并合并为一个“保存释义与备注”操作；认识程度继续由上方四档按钮单独保存。
