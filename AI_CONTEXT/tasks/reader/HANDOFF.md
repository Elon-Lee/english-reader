# PC 阅读器交接

## 目标

React 阅读器统一精读能力，只保留普通 / 专注两种呈现模式，使用 SaaS API 和鉴权原媒体。2026-10-20 用户新方向已本地实施，覆盖上一轮“阅读 / 精读”切换建议；未发布生产。

- 阅读器和系统设置均取消阅读/精读/影子模式选择。前端不再读取或发送 readerMode，兼容忽略数据库既有值；不新增迁移。系统设置通过现有 preferences API 保存普通/专注布尔值。
