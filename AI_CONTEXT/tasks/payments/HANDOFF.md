# 支付功能已撤除

更新时间：2026-11-09（Asia/Shanghai）

## 当前状态

根据用户指令，线上支付、会员、订阅与商品流程已删除。当前状态以 [纸间微光私域改造](../private-paper-glow/HANDOFF.md) 为准。

- 删除支付宝、Paddle、MBDPay/云猫支付与兑换运行模块，以及下单、收款通知、模拟支付、退款、后台支付配置和订单操作接口。
- 删除支付前端、图片、购买恢复、套餐与付费权益；旧接口返回 404。
- 环境样例不再提供支付参数；独立本地环境过滤旧支付变量，后续部署升级脚本移除旧渠道环境项。
- 已执行的迁移 SQL 和历史数据库记录保留，不重写迁移链、不删历史交易、不读取或输出旧支付密钥。
- 历史 `platform_settings` 中的支付设置没有运行读取或公开管理入口。现有远端环境未被本轮更改。

## 验证与边界

旧接口回归、隔离数据库 HTTP smoke、前端构建/浏览器及部署脚本验证详见私域改造交接。本轮未部署或连接支付渠道；真实支付联调、支付产品申请和上架不再是本项目后续待办。
