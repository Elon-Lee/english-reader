# 纸间微光双站设计

用户已确认 Astro + Retypeset 方案，授权完成后发布京东云。

- `rynenglish.com` 为独立静态博客，Retypeset 定制米白纸色、中文衬线字、暖色点缀；提供首页、文章、标签归档、关于、RSS、sitemap、404。用 Markdown 写作，不加入评论、账号或收款。
- `learn.rynenglish.com` 承载现有受邀阅读应用及全部 API、鉴权媒体，保持 React + Ant Design 和账号/租户/CSRF 权限。邮件基础地址与元信息跟随子域名；Cookie 保持 host-only。
- 主站独立构建目录，页面及其静态资源、RSS、sitemap 不包含阅读子站的地址、链接或业务代码。对所有 User-Agent 使用相同路由，不设置面向抽查的特殊响应。
- 前端服务按准确 Host 分站；主站 `/api`、`/login`、阅读路径均 404，不重定向到子站；未知公网 Host 拒绝。仅本机且无转发头的内部健康请求可以使用原应用入口。未启用双站配置时保持原本地开发行为。
- 京东云保留现有数据库、媒体与密钥；升级先备份并执行候选检查。HTTPS 使用双站配置与证书续期，后续升级不能覆盖回单站配置。
- 首批文章使用明确的站点介绍与阅读笔记写作方法，不冒充站长真实生活经历；不导入主题演示文章或第三方统计/评论凭据。保留上游 MIT 许可及来源版本。
- 验收：博客构建/类型检查、真实浏览器首页及文章、离线资源与子域名字符串审计；真实 HTTP 双 Host/API/方法/遍历隔离；原应用相关测试、Python 编译、diff 检查、发布包包含双站资源；远端严格 TLS、两个域名健康与页面验收。

发布外部条件：SSH 私钥由用户提供，本机仅读取；`learn` DNS 必须存在，京东云必须放行对应域名。若外部条件未满足，完成本地和服务器可验证部分并准确记录，不将源站验证当公网发布成功。
