# 国内与国际入口共享业务设计

用户已于 2026-11-12 确认实施。以当前 `7a0d16e` 为基线，在 `feat/dual-entry-commerce` 开发。

同一提交构建国内与国际 React 产物。共同阅读、导入、账号与内容管理使用当前源码，国际首页、会员、商品、订单、支付和兑换从删除前 `844d07c` 定向迁回并适配，不回退共同业务。国内商业页面不进入构建依赖图，公共资源也需按构建隔离。

国际前端监听回环 5173，国内前端监听回环 5174，均代理同一回环 API 8790。Cloudflare 保留国际回源，国内 Nginx 转发 5174；博客与 learn 按 Host 提供不同目录。数据库、Redis、媒体与验证码保持一套。

服务端按可信入口识别站点：国内与国际前端分别持有独立入口凭据，覆盖客户端内部站点头；后端只在回环来源及凭据匹配后接受站点身份，并校验对应域名。国内商业页面/API 返回 404，国际商业 API 继续要求原有认证、管理员权限、CSRF、支付签名与幂等。健康探针不披露身份。站点差异不依据 User-Agent 或爬虫身份。

权益按账号统一，现有私人账号保留资源额度；新增国际账号按免费/付费规则，付费权益两个入口一致。不同时运行旧后端与新后端。0044 已允许计划字段为空，恢复模块需显式兼容并以增量迁移完成，不能改写既有迁移。

两域会话分别登录；邮件验证、密码重置与支付返回使用站点白名单基础地址，不能从未验证 Host 构造。已退役支付渠道继续关闭，未配置渠道显示明确不可用，不能把模拟支付作为生产支付。

发布包包含两个前端与共享后端，候选端口验收后切换；保留数据库备份并整体回退代码与站点配置。站点配置持久化端口、域名与国际入口，后续升级不覆盖。国内公网 TLS 取决于实际 DNS/云商放行，国际接入仍回源当前京东云。

验收覆盖双构建与资源隔离、两入口相同账号数据和额度、伪造站点头拒绝、国内商业路由拒绝、邮箱链接、支付验签/金额/幂等、候选与回退，以及实际源站和 Cloudflare 严格 TLS。
